# SOC Analyst Projects

## About
This repository contains my hands-on Security Operations Center (SOC) projects focused on security monitoring, log analysis, threat detection, and incident investigation.

I am building practical cybersecurity skills to prepare for a SOC Analyst Tier 1 role. Through these projects, I aim to understand how security tools collect and analyze logs, detect suspicious activities, generate alerts, and support incident response.

## Projects
### 1. Splunk SIEM Lab
Tool: Splunk

* SIEM setup and configuration
* Log ingestion and analysis
* Searching and investigating security events
* Detecting suspicious activities
* Creating dashboards and alerts

[Project Folder](./Splunk-SIEM-Lab)
